# 优衣库门店运营工具箱（原型 v2.0）

一个面向优衣库门店运营的网页工具原型，把「超级店长的判断力」拆成五个可操作的模块：

1. **天气/客流预判** —— 按场景（降温/升温/暴雨/客流高峰…）提示备货、陈列、话术
2. **策略库** —— 把优秀店员动作沉淀成可复制的标准策略（本地保存）
3. **问题定位** —— 对照策略库自评，找出差在哪一步、怎么补
4. **店长点检** —— 店长一日经营点位的点检清单（进店→营业→闭店）
5. **上下游·市场** —— 优衣库供应链、门店、市场走向的认知

## 怎么打开

单文件 HTML（`index.html`），双击即用，策略库用 localStorage 本地保存，不依赖任何后端和外部接口。

## 定位

> 一面后迭代升级的 v2.0：从「帮店员做营销」转向「帮店长做经营」。
> 不是替代店长，是把「靠经验拍脑袋」变成「有数据、有方法、能复制」。
